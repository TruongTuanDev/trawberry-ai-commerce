## AI Try-On locale scope

- public/customer AI Try-On copy is available only in `ru` and `en`
- seller `vi` was intentionally not exposed on the public/customer try-on path
- admin AI settings page is English-only and does not use locale switching

AI Try-On public strings added for:

- CTA and disabled-state feedback
- size-selection warning
- modal headings and form labels
- body traits
- upload/model selection
- loading/result states
- consent copy
- size recommendation disclaimer

## Locale switcher flags

- The shared language switcher now renders local SVG flag icons for `RU`, `EN`, and `VI` instead of text-like pseudo-icons.
- Role policy is unchanged:
  - public/customer: `RU/EN`
  - seller: `RU/EN/VI`
  - admin: English only, no switcher
- Locale metadata now maps to stable local flag keys, while the dropdown keeps the existing live-switch and persistence behavior.

## Role policy

- Admin:
  - supported locales: `en`
  - default locale: `en`
  - no language switcher
- Seller:
  - supported locales: `ru`, `en`, `vi`
  - default locale: `ru`
  - language switcher visible in Seller Center
- Public / customer:
  - supported locales: `ru`, `en`
  - default locale: `ru`
  - language switcher visible in public surfaces

## Resolution order

1. logged-in user `preferredLocale`
2. locale cookie
3. role default

Current phase intentionally does not let browser language override the public default Russian fallback.

## Homepage Slides and Image Slider

- Public / customer:
  - Supported locales: `ru`, `en`
  - Default locale: `ru`
  - Vietnamese (`vi`) is not exposed in the public slider dropdown or content. If the active locale is Vietnamese, the public homepage hero slider falls back to `en` safely.
  - Localization is applied to the overlay title, subtitle, CTA button labels, and image alt texts using `en.json` and `ru.json` fallback key paths (`home.heroFallbackTitle`, `home.heroFallbackSubtitle`, `home.heroCtaFallback`, `home.bannerAltFallback`).
- Admin Management:
  - Admin page `/admin/homepage-slides` is English-only.
  - Creation, editing, deletion, and preview controls are fully localized in English.
